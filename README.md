Billing System
Project Description

The Billing System is a Windows Forms application developed in C# using Visual Studio. It is designed to manage customer information and billing records in an organized and user-friendly system.

This project was created as part of our Version Control and Team Collaboration activity to demonstrate how Git and GitHub can be used by multiple developers working on the same project.

Version Control Workflow:

Our team used Git and GitHub to collaborate on the project.

1. The Repo Owner created and managed the repository.
2. Developers created their own branches.
3. Each developer worked on their assigned changes.
4. Changes were committed and pushed to their respective branches.
5. Pull Requests were created for reviewing changes.
6. Approved changes were merged into the main project.
7. Merge conflicts were resolved by comparing the conflicting changes and keeping the correct combined version.

Purpose:

This project demonstrates both software development and team collaboration using version control. It shows how branches, commits, Pull Requests, and merge conflict resolution can be used to manage changes in a shared project.
